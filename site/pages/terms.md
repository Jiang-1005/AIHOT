页首说明：

> 本站只供内部使用，不面向公众开放。站点聚合公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内默认只展示摘要和原文链接。

## 2. 内部使用

内容仅供团队讨论产品与行业动态，不要对外公开发布整页镜像，也不要把访问地址发到团队以外。转发单条摘要时请附上原文链接。

## 3. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过站内反馈页联系。

## 4. 接口

RSS、公开 API 与 MCP 默认可用，但整站加了访问门禁，只应在团队内部使用。请按响应中的缓存时间轮询。

## 5. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。模型评分是编辑判断的辅助，不是事实本身。
